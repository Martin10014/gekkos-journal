# Release notes

## 0.1.4 — 8 November 2026

- Added quiet GitHub update notices. Checks run after startup and at most every
  six hours; Settings includes a manual check and an automatic-check switch.
  Open the trusted release page when ready, or dismiss that version's notice.
- Right-click any evidence entry for confirmation, rule-out and hidden-evidence
  guidance without changing your marks.
- Added equipment comparisons for all three tiers of the seven evidence tools.
- Added conditional fuse-box clues for Hantu and Jinn, distinguishing direct
  ghost interactions from player switching and circuit overloads. These remain
  advisory observations.

Install this update once to receive future update notices. The setup installer
and portable ZIP both include these changes, and existing preferences are kept.

## 0.1.3 — 8 November 2026

- Added a ghost gender filter: Male rules out Banshee and Dayan; Female adds no
  rule-outs. Match the gender icon beside the ghost’s name in-game.
- Added small, labelled **Gender ? / ♂ / ♀** controls in the Evidence page footer,
  with muted icons, a subtle selected underline and help on hover.
- Clear the gender choice with **?** or by clicking the selected icon again.
  Gender works with other filters, Undo, New game and shared journals while
  keeping the ghost roster in its usual positions.

The setup installer and portable ZIP both include these updates. Close the
journal before updating; your preferences are kept.

## 0.1.2 — 8 November 2026

- Hover a ghost name to temporarily cross out evidence that does not fit it.
  Moving away restores your view; your marks and filters stay unchanged.
  The Mimic’s preview includes its extra Ghost Orbs.
- Left-click ghost names to cycle Selected (Maybe) → Crossed out → Clear,
  directly in the journal. Each click is a single undoable action.
- Right-click a ghost name to open its notes and tests, including crossed-out
  ghosts. Updated hints explain the controls.

The setup installer and portable ZIP both include these updates. Close the
journal before updating; your preferences are kept.

## 0.1.1 — 8 November 2026

- Matched the ghost list to the in-game journal: alphabetical rows across three

- Fixed brief extra windows appearing when opening or refreshing ghost notes.
- Added a custom leather-journal and ghost icon to the app, taskbar, shortcuts
  and installer. Loading and notes windows use the same icon.

The setup installer and portable ZIP both include these updates. Close the
journal before updating; your preferences are kept.

## 0.1.0 — 7 November 2026

First public Windows preview of Gekko’s Journal.

- Paper-style evidence journal with seven evidence marks and a 30-ghost roster.
- Behavior observations, hunt-speed ticks and conditional hunt-sanity guidance.
- Ghost tests, shortlists, comparisons, current-game notes and undo.
- Timers, footstep tapping, sanity estimates and reference tools.
- Optional pocket view, hotkeys, Windows voice commands and private-network sharing.
- Fresh investigations on launch and **New game**; only preferences persist.
- A single dark startup screen and persistent pages for smooth tab changes.

Windows x64 setup installer is the recommended download. It installs for the
current user without administrator access, creates a Start Menu shortcut, offers
an optional desktop shortcut and adds an uninstaller to Windows Settings.
Reinstalling or updating keeps preferences; uninstalling also leaves preferences
available for a later reinstall.

The original portable ZIP remains available. Extract the entire folder and run
`GekkosJournal.exe`. Both downloads contain the same version 0.1.0 application.

The installer and app are unsigned. To update, close the journal and run the newer
setup file, or extract the newer portable ZIP into a new folder.

The main application is closed source. Third-party LGPL source archives are
included as separate release downloads to accompany the bundled Qt libraries.
